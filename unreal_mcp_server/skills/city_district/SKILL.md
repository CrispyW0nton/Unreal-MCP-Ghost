# City/District Generation Skill

Use `skill_generate_city_district` to compile a no-mutation plan or tool queue for a native-aligned Unreal city/district workflow.

The skill composes Ghost's differentiators with native Unreal systems:

- PCG support checks, graph asset shells, PCG volumes, and refresh wrappers.
- World Partition edit-region setup.
- Data Layer creation.
- Blueprint spline and ISM blockout fallbacks.
- HLOD assignment/build reporting.
- Screenshot evidence.
- Optional MassEntity and SmartObject scaffolding.

This skill is intentionally a scaffold, not a claim of full Unreal city-sample parity. Full production city generation still needs deeper PCG graph node authoring, ZoneGraph/MassTraffic wrappers, streaming validation, actor/Data Layer assignment automation, and performance evidence.
