# Insanitii Project Knowledge Base

## Project Direction

Insanitii is a mechanics-first Unreal Engine 5.6 first-person project focused on validating core psychosis simulation systems before custom content production.

Current source of truth as of 2026-05-18: Insanitii uses a **best-fit native C++ logic + Blueprint wrapper** architecture. Native classes can own stable core runtime mechanics where that is cleaner or safer; Blueprint wrappers under `/Game/Insanitii/...` keep systems designer-accessible for tuning, presentation, and content wiring.
